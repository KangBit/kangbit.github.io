# 10. 분석 기록과 복기

기억에 의존하지 않고 자신의 판단을 검증할 수 있게 만드는 방법을 정리합니다.

## 왜 기록하는가

기억은 결과에 맞춰 바뀝니다. 오른 종목은 "그럴 줄 알았다"가 되고, 떨어진 종목은 "사실 좀 불안했다"가 됩니다. 이것을 사후확신 편향이라고 합니다.

기록하지 않으면 **무엇을 배웠는지 알 수 없습니다.** 같은 실수를 반복하면서도 반복하고 있다는 사실을 모릅니다.

기록의 목적은 수익률 관리가 아니라 **판단 과정의 검증**입니다. 결과는 증권사 앱이 알려 주지만, 왜 그렇게 판단했는지는 본인만 남길 수 있습니다.

## 분석 시점과 자료 출처 기록

모든 판단에는 **그때 가지고 있던 정보**라는 전제가 붙습니다. 그 전제를 적지 않으면 나중에 평가할 수 없습니다.

```
작성일: 2026-10-26
기준 자료: 2026년 반기보고서 (2026-08-14 공시)
주가: 52,300원 (2026-10-25 종가)
시가총액: 5.2조 원
```

출처를 적어 두면 나중에 같은 자료를 다시 펼칠 수 있습니다. "어디서 봤더라"로 시간을 쓰지 않아도 됩니다.

**기준 시점이 중요한 이유**는 그 이후에 나온 정보로 과거의 판단을 탓하지 않기 위해서입니다. 반기보고서만 보고 내린 판단을 3분기 실적을 알고 나서 평가하면 공정하지 않습니다.

## 사실, 추정과 의견 구분

한 문단 안에 섞여 있으면 나중에 무엇을 검증해야 할지 알 수 없습니다.

```
[사실]
- 2026년 상반기 매출 8,200억 원, 전년 동기 대비 +18%
- 영업이익률 11.2% (전년 동기 12.8%)
- A 고객사 비중 42% (사업보고서 II-4)

[추정]
- 이익률 하락은 원재료 가격 상승 때문으로 보인다
- 하반기에도 비슷한 압력이 이어질 것 같다

[의견]
- 고객 집중도가 높아 거래처 변동 위험이 크다고 생각한다
- 현재 가격은 성장이 유지된다는 가정을 반영하고 있다
```

구분하는 기준은 단순합니다.

| 구분 | 판별법 |
| --- | --- |
| 사실 | 자료에서 그대로 확인할 수 있습니다 |
| 추정 | 사실에서 추론한 것입니다. 틀릴 수 있습니다 |
| 의견 | 가치 판단입니다. 맞고 틀림이 없습니다 |

시간이 지나 검토할 때 **추정만 평가하면 됩니다.** 사실은 바뀌지 않고, 의견은 검증 대상이 아닙니다.

## 차트 관찰 시점, 기간과 지표 설정 기록

차트를 근거로 삼았다면 **그때 무엇을 어떻게 봤는지** 적어야 재현할 수 있습니다.

```
관찰일: 2026-10-26
주기: 주봉 (2024-01 ~ 2026-10)
수정주가 적용: 예
스케일: 로그

관찰한 사실
- 2026-03 이후 고점과 저점이 모두 낮아지고 있다
- 2026-09-12 거래량이 평균의 6배, 당일 −9%
  → 같은 날 3분기 실적 하향 공시 확인

사용한 지표
- 20주 이동평균선
- RSI(14)
```

지표의 **설정값까지** 적습니다. RSI(14)와 RSI(9)는 다른 신호를 냅니다. 나중에 "그때 과매도였다"고만 적혀 있으면 어느 설정이었는지 알 수 없습니다.

차트에서 이상한 구간을 발견했다면 **실제 원인을 자료에서 확인한 뒤** 적습니다. 차트만 보고 원인을 상상한 것과 공시로 확인한 것은 신뢰도가 다릅니다.

## 판단 근거와 재검토 조건 정리

여기가 기록의 핵심입니다. **무엇을 보면 내가 틀렸다고 인정할 것인지** 미리 정합니다.

```
핵심 가정
1. A 고객사와의 거래가 유지된다
2. 영업이익률이 11% 아래로 떨어지지 않는다
3. 신규 B 사업이 2027년부터 매출에 기여한다

재검토 조건
- A 고객사 비중이 30% 아래로 떨어지거나 계약 변경 공시가 나오면
- 2개 분기 연속 영업이익률 10% 미만이면
- B 사업 일정이 6개월 이상 밀리면
- 경쟁사가 같은 기술로 진입하면
```

이것을 미리 적는 이유는, 나중에는 적을 수 없기 때문입니다. 손실 중일 때는 **팔지 않을 이유를 찾게 됩니다.** 기준이 없으면 "조금만 더 기다려 보자"가 무한히 연장됩니다.

반대 경우도 적어 둡니다.

```
가정이 맞아떨어지는 신호
- B 사업 수주 공시
- 이익률이 13% 이상으로 회복
```

판단 근거를 적을 때 피해야 할 표현이 있습니다.

```
"요즘 분위기가 좋다"          — 검증할 수 없습니다
"차트가 좋아 보인다"          — 무엇이 어떻게 좋은지 적습니다
"다들 좋다고 한다"            — 근거가 아닙니다
"많이 떨어져서 싸 보인다"      — 떨어진 것과 싼 것은 다릅니다
```

**검증 가능한 문장으로 적는 것**이 기준입니다. 적어 놓고 보면 근거가 빈약했다는 것이 드러나기도 합니다. 그 자체가 유용한 결과입니다.

## 새로운 공시와 실적에 따른 가정 점검

기록은 한 번 쓰고 덮는 것이 아닙니다. 새 정보가 나올 때마다 **가정이 여전히 유효한지** 확인합니다.

분기 실적이 나왔을 때 하는 작업입니다.

```
[2026-11-14 3분기 실적 확인]

가정 1 (A 고객 유지)      → 비중 39%로 소폭 하락. 유지로 판단
가정 2 (이익률 11% 이상)  → 10.4%. 기준에 미달
가정 3 (B 사업 2027년)    → 일정 변동 언급 없음

조치: 가정 2가 재검토 조건에 걸림.
     원인을 확인한 결과 일회성 비용이 포함되어 있어
     이것을 제외하면 11.3%. 다음 분기까지 지켜보기로 함.
     단, 2개 분기 연속 미달이면 조건대로 재검토.
```

**조건에 걸렸을 때 그냥 넘어가지 않는 것**이 중요합니다. 넘어가더라도 왜 넘어가는지 적어 두면, 나중에 그 판단 자체를 평가할 수 있습니다.

정기적으로 확인할 일정을 정해 두면 놓치지 않습니다.

```
분기 실적 발표 후 1주 이내 — 가정 점검
반기 1회 — 투자 논리 전체 재검토
수시 — 주요 공시 발생 시
```

## 결과와 판단 과정의 구분

가장 중요한 부분입니다. **결과가 좋았다고 판단이 옳았던 것은 아닙니다.**

| | 결과 좋음 | 결과 나쁨 |
| --- | --- | --- |
| **과정 좋음** | 그대로 유지 | 운이 나빴습니다. 과정을 바꾸지 않습니다 |
| **과정 나쁨** | **가장 위험합니다** | 과정을 고칩니다 |

오른쪽 위 칸이 함정입니다. 근거 없이 샀는데 올랐다면, 그 방식이 통한다고 학습하게 됩니다. 몇 번 반복되면 확신이 생기고, 금액을 키운 뒤에 무너집니다.

복기할 때 물을 것은 결과가 아니라 과정입니다.

```
그때 알 수 있었던 정보로 그 판단이 합리적이었나
빠뜨린 자료가 있었나
가정 중 틀린 것은 무엇이었나
그것을 미리 알 수 있는 방법이 있었나
없었다면 — 알 수 없는 영역이었다는 것을 인정합니다
```

마지막 항목도 중요한 결론입니다. **모든 것을 예측할 수는 없습니다.** 알 수 없었던 일에 대해 자신을 탓하면, 다음에는 과도하게 조심하게 됩니다.

반복되는 패턴이 보이면 적어 둡니다.

```
- 하락장에서 계획보다 빨리 판다
- 익숙한 업종에 과도하게 비중을 둔다
- 손실 중인 종목의 나쁜 소식을 과소평가한다
```

이런 것들은 한 번의 기록으로는 보이지 않고, **여러 건이 쌓여야** 드러납니다.

## 기록의 형식

도구는 중요하지 않습니다. 텍스트 파일이든 노트든 상관없습니다. 다만 몇 가지는 지키는 편이 좋습니다.

- **종목마다 하나의 문서**를 두고 계속 추가합니다
- 새 내용은 날짜를 붙여 **아래에 덧붙입니다.** 이전 내용을 고치지 않습니다
- 고쳐야 한다면 **"수정: 이전 판단이 틀렸음"**으로 남깁니다

이전 내용을 지우면 자신이 무엇을 생각했는지 추적할 수 없습니다. 틀린 기록이 가장 쓸모 있습니다.

```
종목명.md

## 2026-10-26 최초 분석
...

## 2026-11-14 3분기 실적 점검
...

## 2027-02-10 가정 수정
이전에 B 사업 기여를 2027년으로 봤으나 일정이 밀렸다.
근거가 되었던 것은 경영진 발언이었는데, 공식 공시가 아니었다.
앞으로는 확정 공시를 기준으로 삼는다.
```

마지막 줄 같은 것이 쌓이면, 자신의 판단 방식이 조금씩 바뀝니다. 그것이 이 과정 전체의 목적입니다.
