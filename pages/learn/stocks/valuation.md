# 06. 가치 평가 기초

지표가 무엇을 요약한 숫자인지, 어디까지 말해 주고 어디서부터는 말해 주지 않는지 정리합니다.

## 가격과 가치의 차이

**가격**은 시장에서 매겨진 숫자이고, **가치**는 그 자산이 앞으로 만들어 낼 것에 대한 추정입니다.

가격은 확인하면 되지만, 가치는 **계산하는 사람의 가정에 따라 달라집니다.** 같은 회사를 두고 전혀 다른 숫자가 나오는 이유입니다.

그래서 가치 평가의 결과는 "이 회사의 가치는 10조 원이다"가 아니라 이런 형태가 됩니다.

```
성장률 5%, 할인율 9%를 가정하면 8~12조 원 범위가 나온다.
성장률이 3%로 낮아지면 6조 원대로 내려간다.
```

**숫자 하나가 아니라 가정과 범위**로 말하는 것이 정직한 결론입니다.

## PER, PBR과 ROE의 의미 및 한계

### PER

```
PER = 주가 ÷ 주당순이익 = 시가총액 ÷ 당기순이익
```

"지금 이익이 계속된다면 원금 회수에 몇 년 걸리는가"로 읽을 수 있습니다. PER 10이면 10년입니다.

**높다고 비싼 것도, 낮다고 싼 것도 아닙니다.** PER은 시장이 기대하는 성장을 반영합니다. 빠르게 성장하는 회사는 높은 PER이 정상이고, 성장이 멈춘 회사는 낮은 것이 정상입니다.

한계가 분명합니다.

- **적자면 계산되지 않습니다**
- 일회성 이익이 섞이면 왜곡됩니다
- 경기민감 산업에서는 **호황기에 PER이 가장 낮아 보입니다.** 이익이 고점이기 때문입니다
- 회계 기준이 다른 기업끼리는 비교가 어렵습니다

세 번째가 특히 함정입니다. 반도체나 철강에서 PER이 3~4로 떨어졌다면 싸진 것이 아니라 **이익이 곧 꺾일 것을 시장이 반영한** 경우가 많습니다.

### PBR

```
PBR = 주가 ÷ 주당순자산 = 시가총액 ÷ 자본총계
```

장부상 순자산 대비 가격입니다. PBR 1 미만은 "장부 가치보다 싸게 거래된다"는 뜻입니다.

다만 **장부 가치가 실제 가치가 아닙니다.**

- 오래전에 산 토지는 취득가로 기록되어 실제보다 낮을 수 있습니다
- 반대로 팔리지 않는 재고나 회수 못 할 채권은 과대평가되어 있을 수 있습니다
- **무형자산이 핵심인 회사**(소프트웨어, 브랜드)는 자산이 장부에 거의 잡히지 않습니다

그래서 PBR은 자산이 실체인 업종(은행, 부동산, 제조)에서 더 의미가 있고, 인력과 브랜드가 핵심인 업종에서는 거의 쓸모가 없습니다.

PBR이 낮은 상태가 오래 지속되는 회사도 많습니다. **싸서 안 오르는 것이 아니라, 안 오를 이유가 있어서 싼** 경우입니다.

### ROE

```
ROE = 당기순이익 ÷ 자본총계
```

주주가 넣은 돈으로 얼마나 벌었는지입니다. 높을수록 자본을 효율적으로 쓰고 있다는 뜻입니다.

세 가지로 분해하면 어디서 나온 수치인지 보입니다.

```
ROE = 순이익률 × 자산회전율 × 재무레버리지
       (수익성)    (효율성)      (부채 사용)
```

**레버리지로 올린 ROE는 위험을 함께 키운 것**입니다. 빚을 많이 쓰면 ROE는 올라가지만, 업황이 나빠지면 그만큼 타격이 큽니다. ROE가 높다면 부채비율을 함께 확인합니다.

세 지표는 연결되어 있습니다.

```
PBR = PER × ROE
```

ROE가 높은 회사가 높은 PBR을 받는 것이 자연스럽습니다. ROE는 낮은데 PBR이 높다면, 시장이 미래의 개선을 기대하고 있는 것입니다.

### 그 외 지표

```
EV/EBITDA = (시가총액 + 순차입금) ÷ (영업이익 + 감가상각비)
```

부채를 포함한 기업 전체 가치를 보기 때문에, 자본 구조가 다른 회사끼리 비교할 때 PER보다 낫습니다. 감가상각이 큰 장치산업에서 많이 씁니다.

적자 기업에는 PSR(매출 대비)이나 사용자당 가치 같은 대체 지표를 쓰기도 하는데, **이익과의 연결이 약해 신뢰도가 떨어집니다.**

## 현금 흐름과 할인율의 기본 개념

지표 비교는 "비슷한 회사들에 비해 어떤가"를 보는 상대적 방법입니다. 절대적인 가치를 추정하려면 **미래에 벌 돈을 현재 가치로 환산**합니다.

핵심은 **오늘의 1만 원과 10년 뒤의 1만 원이 다르다**는 것입니다. 기다리는 대가와 못 받을 위험이 있기 때문입니다.

```
현재가치 = 미래 현금 ÷ (1 + 할인율)^기간
```

할인율 10%에서 1년 뒤 110만 원은 지금 100만 원과 같습니다.

**할인율은 위험이 클수록 높아집니다.** 안정적인 회사는 낮은 할인율을, 변동이 큰 회사는 높은 할인율을 적용합니다.

여기서 중요한 사실이 하나 있습니다. **할인율을 조금만 바꿔도 결과가 크게 달라집니다.**

| 할인율 | 영구히 연 100억을 버는 사업의 가치 |
| --- | --- |
| 8% | 1,250억 |
| 9% | 1,111억 |
| 10% | 1,000억 |
| 12% | 833억 |

2%포인트 차이로 가치가 33% 달라집니다.

성장률 가정도 마찬가지입니다. 먼 미래의 성장률을 1%포인트 높이면 현재 가치가 수십 퍼센트 뜁니다.

그래서 정밀하게 계산한 DCF 결과를 **정확한 답으로 받아들이면 안 됩니다.** 소수점까지 나온 숫자여도, 그것은 몇 개의 가정이 만들어 낸 결과일 뿐입니다.

이 계산의 진짜 쓸모는 숫자 자체가 아니라, **지금 가격이 성립하려면 어떤 가정이 필요한지** 거꾸로 확인하는 데 있습니다.

```
현재 가격이 정당화되려면 향후 10년간 연 25% 성장이 필요하다.
→ 그게 가능한 시장 규모인가?
```

## 성장률과 수익성에 대한 가정

평가에 쓰는 가정은 적는 순간 검증할 수 있게 됩니다.

| 가정 | 확인할 것 |
| --- | --- |
| 매출 성장률 | 시장 규모가 그만큼 되는가 |
| 영업이익률 | 과거에 그 수준을 달성한 적이 있는가 |
| 설비투자 | 성장하려면 얼마나 더 투자해야 하는가 |
| 영구성장률 | 경제 성장률을 넘지 않는가 |

마지막 항목이 자주 틀립니다. 영구성장률을 경제 성장률보다 높게 두면, 언젠가 그 회사가 경제 전체보다 커진다는 뜻이 됩니다.

과거 추세를 그대로 연장하는 것도 흔한 오류입니다. 최근 3년간 30% 성장했다고 앞으로 10년도 그럴 것이라 가정하면, **기저가 커질수록 같은 성장률이 어려워진다**는 사실을 무시하게 됩니다.

```
매출 100억에서 30% = 30억 추가
매출 1조에서 30% = 3,000억 추가
```

## 가정을 달리한 시나리오 비교

하나의 숫자 대신 **범위**를 만듭니다.

| | 비관 | 기본 | 낙관 |
| --- | --- | --- | --- |
| 매출 성장률 | 2% | 6% | 12% |
| 영업이익률 | 8% | 12% | 15% |
| 추정 가치 | 6조 | 10조 | 18조 |
| 현재 시가총액 | | 9조 | |

이렇게 놓으면 판단할 수 있는 것이 생깁니다.

- 현재 가격은 기본 시나리오에 가깝습니다
- 비관 시나리오가 현실이 되면 33% 하락 여지가 있습니다
- 낙관 시나리오를 기대한다면 **무엇이 그것을 만들어 낼지** 설명할 수 있어야 합니다

**어떤 변수가 결과를 가장 크게 움직이는지**도 확인합니다. 영업이익률 1%포인트가 성장률 3%포인트보다 영향이 크다면, 앞으로 추적해야 할 것은 이익률입니다.

가치 평가를 하는 이유는 정확한 가격을 맞히기 위해서가 아닙니다. **지금 가격에 어떤 기대가 담겨 있는지 파악하고, 그 기대가 합리적인지 따져 보기 위해서**입니다.

그 과정에서 세운 가정은 반드시 적어 둡니다. 시간이 지나 실제 실적이 나왔을 때, 무엇이 맞고 무엇이 틀렸는지 확인할 수 있는 유일한 방법입니다.
