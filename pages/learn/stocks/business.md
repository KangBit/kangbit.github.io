# 04. 기업과 사업 분석

숫자를 보기 전에, 이 회사가 무엇을 해서 돈을 버는지 먼저 이해합니다.

## 사업보고서와 공시의 구조

한국 상장사의 공시는 **DART**(전자공시시스템)에 모두 모여 있습니다. 증권사 앱의 요약 정보가 아니라 원문을 보는 습관이 필요합니다.

정기공시는 주기적으로 나옵니다.

| 공시 | 시기 |
| --- | --- |
| 사업보고서 | 사업연도 종료 후 90일 이내 |
| 반기보고서 | 반기 종료 후 45일 이내 |
| 분기보고서 | 분기 종료 후 45일 이내 |

사업보고서가 가장 자세합니다. 처음 보는 기업이라면 여기부터 읽습니다.

사업보고서에서 먼저 볼 항목은 정해져 있습니다.

| 항목 | 알 수 있는 것 |
| --- | --- |
| II. 사업의 내용 | 무엇을 팔아 돈을 버는지 |
| III. 재무에 관한 사항 | 재무제표와 주석 |
| II-7. 주요 계약 | 매출을 좌우하는 계약 |
| X. 대주주 등과의 거래 | 특수관계자 거래 |
| XI. 그 밖에 투자자 보호 | 소송, 제재 이력 |

**수시공시**는 중요한 일이 생겼을 때 즉시 나옵니다. 유상증자, 대규모 계약, 최대주주 변경, 감사의견 거절 같은 것들입니다.

관심 종목은 DART의 알림 기능을 걸어 두면 놓치지 않습니다.

읽을 때 유용한 습관이 있습니다. **전년도 사업보고서와 비교**하는 것입니다. 작년에는 있었는데 올해 사라진 문장, 새로 추가된 위험 요인이 가장 많은 정보를 담고 있습니다.

## 주요 제품, 고객과 수익 모델

"이 회사는 무엇을 팔아 돈을 버는가"에 한 문장으로 답할 수 있어야 합니다.

사업보고서의 매출 구성 표에서 확인합니다.

```
사업부문   매출액    비중
A 부문     8,000억   70%
B 부문     2,500억   22%
기타         900억    8%
```

비중이 큰 쪽이 실제 그 회사의 정체입니다. 이름은 종합기업인데 매출의 90%가 한 품목에서 나오는 경우가 흔합니다.

확인할 것들입니다.

- **매출의 성격** — 한 번 팔고 끝인가, 반복해서 들어오는가
- **고객 집중도** — 특정 고객 한 곳이 매출의 큰 비중을 차지하는가
- **가격 결정력** — 회사가 가격을 올릴 수 있는가, 받아들여야 하는가

고객 집중도는 위험 신호가 될 수 있습니다. 한 고객이 매출의 절반을 차지한다면, 그 고객이 거래처를 바꾸는 순간 회사가 반토막 납니다. 사업보고서에 주요 매출처 비중이 나옵니다.

수익 모델의 성격도 다릅니다.

| 유형 | 특징 |
| --- | --- |
| 일회성 판매 | 매 기간 새로 팔아야 합니다 |
| 구독·계약 | 예측 가능하고 이탈률이 중요합니다 |
| 사용량 기반 | 고객의 활동에 따라 변동합니다 |
| 플랫폼 수수료 | 거래액이 커질수록 늘어납니다 |

같은 1,000억 매출이라도 매년 새로 만들어야 하는 매출과 자동으로 들어오는 매출은 가치가 다릅니다.

**비용 구조**도 함께 봅니다. 고정비 비중이 크면 매출이 조금만 늘어도 이익이 크게 늘고, 줄면 크게 줄어듭니다. 변동비 중심이면 그 진폭이 작습니다.

## 시장 규모, 경쟁사와 경쟁 우위

회사만 보면 판단할 수 없습니다. **시장 안에서의 위치**를 봐야 합니다.

```
시장이 커지고 있는가, 줄고 있는가
그 안에서 이 회사의 점유율은 오르는가, 내리는가
```

시장이 줄어드는데 점유율이 올라가는 것과, 시장이 커지는데 점유율이 떨어지는 것은 전혀 다른 상황입니다.

경쟁사와 비교할 때는 같은 항목을 나란히 놓습니다.

| | 이 회사 | 경쟁사 A | 경쟁사 B |
| --- | --- | --- | --- |
| 매출 성장률 | | | |
| 영업이익률 | | | |
| 시장 점유율 | | | |

**이익률이 경쟁사보다 꾸준히 높다면 이유가 있어야 합니다.** 그 이유를 설명할 수 없다면, 그 차이는 지속되지 않을 가능성이 있습니다.

경쟁 우위는 "왜 고객이 경쟁사 대신 이 회사를 고르는가"에 대한 답입니다.

| 유형 | 내용 |
| --- | --- |
| 전환 비용 | 바꾸기 번거롭거나 비용이 듭니다 |
| 네트워크 효과 | 쓰는 사람이 많을수록 가치가 큽니다 |
| 원가 우위 | 같은 것을 더 싸게 만듭니다 |
| 무형자산 | 브랜드, 특허, 인허가 |
| 규모의 경제 | 클수록 단위 비용이 낮아집니다 |

중요한 것은 **그 우위가 얼마나 오래 가는가**입니다. 기술 우위는 따라잡히고, 특허는 만료되고, 브랜드는 희석될 수 있습니다.

## 산업의 경기 민감도와 주요 위험 요인

산업마다 경기에 반응하는 정도가 다릅니다.

| 성격 | 예시 산업 | 특징 |
| --- | --- | --- |
| 경기민감 | 반도체, 철강, 건설, 자동차 | 호황과 불황의 진폭이 큽니다 |
| 경기방어 | 식품, 통신, 유틸리티 | 상대적으로 안정적입니다 |

**경기민감 산업에서는 이익이 좋아 보일 때가 고점일 수 있습니다.** 호황기 이익으로 계산한 지표는 좋게 나오지만, 사이클이 꺾이면 이익이 급감합니다. 여러 해에 걸친 평균을 함께 보는 이유입니다.

위험 요인은 사업보고서에 **회사가 직접 적어 둡니다.** 형식적인 문구가 많지만, 그 안에 구체적인 내용이 섞여 있습니다.

읽을 때 구분합니다.

- 모든 회사에 해당하는 일반적 문구
- **이 회사에만 해당하는 구체적 위험** ← 이쪽을 봅니다

확인할 만한 것들입니다.

- 원재료 가격과 환율에 얼마나 노출되는가
- 규제가 바뀌면 어떤 영향을 받는가
- 소송이나 제재가 진행 중인가
- 차입금 만기가 몰려 있지 않은가
- 특수관계자와의 거래 비중이 비정상적으로 크지 않은가

마지막 항목은 주의 깊게 봅니다. 대주주 개인 회사와의 거래가 많다면 이익이 어디로 흘러가는지 확인할 필요가 있습니다.

## 정리하는 방법

읽은 내용을 자신의 말로 적어 두면 이해했는지 바로 드러납니다. 막히는 부분이 아직 모르는 부분입니다.

```
이 회사는 ___를 ___에게 팔아서 돈을 번다.
매출의 ___%가 ___에서 나온다.
경쟁사보다 나은 점은 ___이고, 그것이 유지되는 이유는 ___이다.
가장 큰 위험은 ___이다.
이 가정이 틀렸다는 것은 ___를 보면 알 수 있다.
```

마지막 줄이 중요합니다. **무엇을 보면 내 판단이 틀렸다고 인정할 것인지** 미리 적어 두면, 나중에 상황이 바뀌었을 때 알아차릴 수 있습니다.

사업 구조를 이해했다면, 이제 그것이 숫자로 어떻게 나타나는지 볼 차례입니다.
