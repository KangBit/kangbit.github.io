# 08. 위험과 포트폴리오

무엇을 위험이라 부를지 정하고, 한쪽으로 쏠리지 않았는지 확인하는 방법을 정리합니다.

## 변동성, 손실과 불확실성

금융에서 **위험**은 보통 변동성으로 측정됩니다. 가격이 얼마나 출렁이는지를 표준편차로 나타냅니다.

편리하지만 한계가 있습니다.

- **오르는 변동과 내리는 변동을 같게 취급합니다.** 올라서 생긴 변동성은 문제가 아닙니다
- **과거를 바탕으로 계산합니다.** 조용하던 자산이 갑자기 폭락하는 경우를 잡지 못합니다
- **영구적 손실과 일시적 하락을 구분하지 못합니다**

마지막이 중요합니다. 실제로 피해야 할 것은 변동이 아니라 **회복되지 않는 손실**입니다.

```
사업이 구조적으로 무너진 회사 → 돌아오지 않습니다
멀쩡한 회사가 시장 전체와 함께 하락 → 돌아올 수 있습니다
```

손실이 깊어질수록 회복에 필요한 수익률이 급격히 커집니다.

| 손실 | 원금 회복에 필요한 수익률 |
| --- | --- |
| −10% | +11% |
| −30% | +43% |
| −50% | +100% |
| −70% | +233% |

**큰 손실을 피하는 것이 큰 수익을 내는 것보다 중요한** 이유입니다.

**불확실성**은 변동성과 다릅니다. 변동성은 확률 분포를 알 때 쓰는 말이고, 불확실성은 분포 자체를 모르는 상태입니다. 실제 투자에서 마주하는 것은 대개 후자입니다.

## 개별 기업 위험과 시장 위험

위험은 두 종류로 나뉩니다.

| 종류 | 내용 | 분산으로 줄일 수 있는가 |
| --- | --- | --- |
| 개별 기업 위험 | 경영 실패, 소송, 사고, 경쟁 탈락 | **줄일 수 있습니다** |
| 시장 위험 | 금리, 경기, 전쟁, 전염병 | 줄일 수 없습니다 |

종목을 여러 개 담으면 개별 기업 위험은 희석됩니다. 하나가 망해도 전체가 무너지지 않습니다.

하지만 **시장 위험은 몇 개를 담든 남습니다.** 전체가 함께 떨어지는 상황에서는 분산이 보호해 주지 못합니다.

종목 수를 늘리는 효과는 금방 둔해집니다. 20~30개를 넘어가면 추가 효과가 거의 없고, 대신 각 종목을 제대로 추적하기 어려워집니다.

**중요한 것은 개수가 아니라 서로 다른 위험을 가졌는가**입니다. 반도체 종목 20개를 담은 것은 1개를 담은 것과 크게 다르지 않습니다.

## 분산과 자산 간 상관관계

**상관관계**는 두 자산이 얼마나 함께 움직이는지입니다. +1이면 완전히 같이, −1이면 정반대, 0이면 무관하게 움직입니다.

분산 효과는 상관관계가 낮을 때 생깁니다. 똑같이 움직이는 것 여러 개는 하나와 같습니다.

```
같은 업종 종목들         상관관계 높음 → 분산 효과 작음
업종이 다른 종목들       상관관계 중간
주식과 채권             상관관계 낮거나 음수인 경우가 있음
```

문제는 **상관관계가 고정되어 있지 않다**는 점입니다.

평소 따로 움직이던 자산들이 **위기 때는 함께 떨어집니다.** 모두가 현금을 확보하려고 팔기 때문입니다. 정작 분산이 필요한 순간에 효과가 줄어드는 셈입니다.

자신도 모르게 한쪽에 쏠려 있는 경우가 흔합니다.

```
종목은 10개인데 전부 반도체 관련
국내 주식만 보유 — 원화와 한국 경제에 전부 걸려 있음
회사 주식 + 그 회사 재직 — 직장과 자산이 같은 위험에 노출
```

마지막이 특히 주의할 조합입니다. 회사가 어려워지면 **급여와 자산이 동시에** 타격을 받습니다.

## 주식, 채권과 현금의 성격 비교

| | 주식 | 채권 | 현금 |
| --- | --- | --- | --- |
| 기대 수익 | 높음 | 중간 | 낮음 |
| 변동성 | 큼 | 중간 | 거의 없음 |
| 인플레이션 | 장기적으로 방어 가능 | 취약 | 취약 |
| 금리 상승 | 불리 | 불리 (가격 하락) | 유리 |

현금은 수익이 없어 보이지만 **선택권**이라는 가치가 있습니다. 가격이 급락했을 때 살 수 있는 여력이 됩니다. 현금이 전혀 없으면 기회가 와도 아무것도 못 합니다.

채권은 주식과 다른 요인에 반응해 완충 역할을 하는 경우가 있습니다. 다만 [07. 금리와 거시 환경](/learn/stocks/macro)에서 본 것처럼, 금리가 급등하면 **주식과 채권이 함께 떨어지기도** 합니다.

비중을 어떻게 가져갈지는 정답이 없습니다. 다만 정할 때 고려할 것은 분명합니다.

```
이 돈이 필요한 시점은 언제인가
얼마나 떨어져도 팔지 않고 버틸 수 있는가
```

두 번째 질문이 핵심입니다. 감당할 수 있는 수준을 넘으면, **가장 나쁜 시점에 팔게 됩니다.**

## 투자 기간, 유동성과 차입의 영향

**투자 기간**이 길수록 단기 변동을 견딜 여지가 커집니다. 반대로 1년 뒤 쓸 돈이라면 변동이 큰 자산에 두기 어렵습니다.

**유동성**은 필요할 때 적정 가격에 팔 수 있는지입니다. 거래량이 적은 종목은 평소에는 괜찮아 보여도, 팔아야 할 때 받아 줄 사람이 없습니다. 비상 자금을 거기에 두면 안 되는 이유입니다.

**차입**은 수익과 손실을 함께 키웁니다. 이 비대칭이 문제입니다.

```
자기 돈 1,000만 원 + 빌린 돈 1,000만 원 = 2,000만 원 투자

주가 +20% → 수익 400만 원 → 자기자본 대비 +40%
주가 −20% → 손실 400만 원 → 자기자본 대비 −40%
주가 −50% → 손실 1,000만 원 → 자기자본 전액 소멸
```

더 큰 문제는 **버틸 수 없다는 것**입니다. 현금으로 샀다면 떨어져도 기다릴 수 있지만, 빌린 돈에는 만기와 담보 비율이 있습니다. 기준에 미달하면 **반대매매로 강제 청산**됩니다.

가격과 시점을 선택할 수 없는 매도라, 하필 바닥에서 팔리는 일이 생깁니다. 나중에 회복되어도 이미 포지션이 없습니다.

신용거래, 미수, 레버리지 ETF 모두 같은 성격입니다. **"장기적으로는 오를 테니 버티면 된다"는 전제가 차입에서는 성립하지 않습니다.**

## ETF의 구조와 비용을 확인하는 방법

ETF는 여러 종목을 묶어 놓은 상품을 주식처럼 거래하는 것입니다. 한 번의 매수로 분산이 됩니다.

고를 때 확인할 것들입니다.

| 항목 | 보는 이유 |
| --- | --- |
| 총보수 | 매년 자동으로 빠집니다 |
| 실부담비용 | 총보수에 숨은 비용까지 포함한 수치 |
| 추적오차 | 지수를 얼마나 잘 따라가는가 |
| 순자산 규모 | 너무 작으면 상장폐지 위험 |
| 거래량 | 적으면 스프레드가 넓습니다 |
| 기초지수 | 실제로 무엇을 담고 있는가 |

**이름만 보고 고르지 않습니다.** 같은 테마를 표방해도 담고 있는 종목과 비중이 크게 다릅니다. 구성 종목 상위 10개는 꼭 확인합니다. 상위 몇 개에 절반이 몰려 있는 경우도 흔합니다.

비용 차이는 장기로 갈수록 커집니다. 연 0.05%와 0.5%는 작아 보이지만, 20년이면 최종 금액에서 10% 가까이 차이가 납니다.

주의가 필요한 유형도 있습니다.

- **레버리지·인버스** — 일간 수익률의 배수를 추종합니다. 기간이 길어지면 지수가 제자리여도 **손실이 누적**됩니다. 장기 보유 목적으로 만들어진 상품이 아닙니다
- **합성 ETF** — 실물을 담지 않고 계약으로 수익률을 받습니다. 거래 상대방 위험이 있습니다
- **환헤지 여부** — `(H)`가 붙으면 환율 변동을 막지만 헤지 비용이 듭니다

## 쏠림을 확인하는 방법

정기적으로 전체를 펼쳐 놓고 확인합니다.

```
업종별 비중      한 업종이 과도하게 크지 않은가
국가·통화별 비중  전부 한 통화에 걸려 있지 않은가
자산군별 비중     주식 일변도인가
상위 종목 비중    한 종목이 전체의 몇 %인가
```

한 종목이 전체의 큰 비중을 차지한다면, **그 하나가 반토막 났을 때 전체가 얼마나 줄어드는지** 계산해 봅니다. 숫자로 보면 체감이 달라집니다.

가정을 바꿔 보는 것도 방법입니다.

```
시장이 30% 하락하면 내 자산은 얼마가 되는가
주력 업종에 악재가 터지면 어떻게 되는가
환율이 반대로 20% 움직이면 어떤가
그 상태에서 나는 팔지 않고 버틸 수 있는가
```

마지막 질문에 자신 있게 답할 수 없다면, **지금 비중이 감당할 수 있는 수준을 넘은 것**입니다. 시장이 조용할 때 조정하는 편이 흔들릴 때 조정하는 것보다 낫습니다.
