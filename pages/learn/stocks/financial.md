# 05. 재무제표 읽기

세 개의 표가 각각 무엇을 보여 주는지, 어떻게 연결되는지 정리합니다.

## 세 표의 역할

| 표 | 보여 주는 것 | 시점 |
| --- | --- | --- |
| 재무상태표 | 지금 무엇을 가지고 무엇을 빚졌는가 | 특정 시점의 스냅샷 |
| 손익계산서 | 기간 동안 얼마를 벌었는가 | 기간 |
| 현금흐름표 | 기간 동안 현금이 어떻게 오갔는가 | 기간 |

손익계산서의 이익은 **회계 규칙에 따라 계산한 숫자**이고, 현금흐름표는 **실제로 통장을 드나든 돈**입니다. 둘이 다르다는 것이 재무제표를 읽는 핵심입니다.

## 재무상태표: 자산, 부채와 자본

```
자산 = 부채 + 자본
```

왼쪽은 가진 것, 오른쪽은 그것을 어디서 조달했는지입니다. 빌려서 마련했으면 부채, 주주가 넣거나 벌어서 쌓았으면 자본입니다.

자산은 현금화 속도로 나뉩니다.

```
유동자산    1년 안에 현금화  — 현금, 매출채권, 재고자산
비유동자산  장기             — 설비, 토지, 무형자산
```

볼 만한 항목들입니다.

**매출채권** — 팔았지만 아직 못 받은 돈입니다. 매출보다 빠르게 늘고 있다면 확인이 필요합니다. 물건은 나갔는데 돈은 안 들어오고 있다는 뜻일 수 있습니다.

**재고자산** — 쌓여 있는 물건입니다. 매출보다 빠르게 늘면 안 팔리고 있을 가능성이 있습니다. 나중에 평가손실로 반영되면 이익이 꺾입니다.

**영업권** — 다른 회사를 비싸게 인수했을 때 생기는 무형자산입니다. 인수한 사업이 기대에 못 미치면 손상차손으로 한꺼번에 털어내며 큰 손실이 납니다.

부채는 성격을 구분합니다.

```
차입금      이자를 내는 빚
매입채무    사고 아직 안 낸 돈 (이자 없음)
```

매입채무가 많은 것은 협상력이 좋다는 신호일 수도 있습니다. 차입금과는 성격이 다릅니다.

**순차입금**을 보면 실질적인 부채 부담이 드러납니다.

```
순차입금 = 총차입금 − 현금성자산
```

부채비율이 높아도 현금을 그만큼 들고 있다면 상황이 다릅니다.

차입금은 **만기 구조**도 봅니다. 1년 안에 갚아야 할 금액이 보유 현금보다 크면, 차환이 막혔을 때 문제가 됩니다.

## 손익계산서: 매출, 영업이익과 순이익

위에서 아래로 빼 나가는 구조입니다.

```
매출액
− 매출원가
────────────
매출총이익
− 판매비와관리비
────────────
영업이익          ← 본업으로 번 것
+ 영업외수익 − 영업외비용
− 법인세
────────────
당기순이익        ← 최종적으로 남은 것
```

**영업이익**이 본업의 성과입니다. 회사가 하는 일 자체가 돈이 되는지를 보여 줍니다.

**당기순이익**에는 본업과 무관한 것들이 섞입니다. 부동산을 팔아 생긴 이익, 환율 변동, 일회성 소송 비용 같은 것들입니다.

순이익이 갑자기 좋아졌다면 **영업이익도 같이 좋아졌는지** 확인합니다. 영업이익은 그대로인데 순이익만 뛰었다면 일회성 요인일 가능성이 큽니다.

이익률로 비교합니다.

```
매출총이익률 = 매출총이익 ÷ 매출
영업이익률   = 영업이익 ÷ 매출
순이익률     = 당기순이익 ÷ 매출
```

**매출이 늘어도 이익률이 떨어지고 있다면** 할인해서 팔고 있거나 원가가 오르고 있는 것입니다. 성장의 질이 다릅니다.

## 현금흐름표: 영업·투자·재무 활동

세 가지로 나뉩니다.

| 구분 | 내용 |
| --- | --- |
| 영업활동 | 본업으로 벌어들인 현금 |
| 투자활동 | 설비 매입, 지분 투자, 자산 매각 |
| 재무활동 | 차입, 상환, 증자, 배당 |

조합을 보면 회사의 상태가 드러납니다.

| 영업 | 투자 | 재무 | 해석 |
| --- | --- | --- | --- |
| + | − | − | 벌어서 투자하고 빚도 갚습니다. 안정적입니다 |
| + | − | + | 벌지만 더 빌려서 크게 투자합니다. 성장기일 수 있습니다 |
| − | − | + | 못 벌면서 빌려서 버팁니다. 주의해야 합니다 |
| + | + | − | 자산을 팔아 빚을 갚습니다. 구조조정 중일 수 있습니다 |

**영업활동 현금흐름이 마이너스인 상태가 이어지는 것**이 가장 위험한 신호입니다. 본업으로 돈을 못 벌고 있다는 뜻입니다.

**잉여현금흐름**은 실제로 주주에게 돌아갈 수 있는 여력을 보여 줍니다.

```
잉여현금흐름 = 영업활동 현금흐름 − 설비투자
```

이 값이 꾸준히 플러스인 회사가 배당이나 자사주 매입을 지속할 수 있습니다.

## 이익과 현금이 다른 이유

이것이 재무제표를 읽는 가장 중요한 지점입니다.

**발생주의** 때문입니다. 회계는 돈이 오간 때가 아니라 **거래가 일어난 때** 기록합니다.

| 상황 | 이익 | 현금 |
| --- | --- | --- |
| 외상으로 팔았다 | 증가 | 변화 없음 |
| 재고를 쌓았다 | 변화 없음 | 감소 |
| 설비를 샀다 | 변화 없음 (감가상각으로 나눠 반영) | 크게 감소 |
| 감가상각비를 인식했다 | 감소 | 변화 없음 |

그래서 **이익이 나는데 현금이 마르는** 상황이 생깁니다. 흑자도산이 이렇게 일어납니다.

반대로 감가상각이 큰 장치산업은 이익이 작아 보여도 현금은 충분할 수 있습니다.

비교해 볼 만한 비율이 있습니다.

```
영업활동 현금흐름 ÷ 영업이익
```

1 근처가 정상입니다. 이 값이 계속 1보다 많이 낮다면, 장부상 이익이 현금으로 바뀌지 않고 있다는 뜻입니다. 매출채권이나 재고가 쌓이고 있을 가능성이 큽니다.

## 주석과 일회성 손익

**주석이 본문보다 중요한 경우가 많습니다.** 숫자 하나로 표시된 것의 내역이 거기 있습니다.

확인할 만한 것들입니다.

- 매출을 **언제 인식하는지**의 기준
- 특수관계자와의 거래 내역
- 우발부채와 진행 중인 소송
- 차입금의 만기와 금리
- 회계정책 변경 여부

**회계정책이 바뀌었다면** 과거와 직접 비교할 수 없습니다. 감가상각 방법이나 내용연수를 바꾸는 것만으로 이익이 달라집니다.

일회성 손익은 **빼고 봐야** 본래 실력이 보입니다.

```
부동산 매각 이익
소송 합의금
자산 손상차손
구조조정 비용
```

회사가 "조정 영업이익" 같은 지표를 제시할 때는, **무엇을 뺐는지** 확인합니다. 매년 반복되는 비용을 일회성이라며 빼고 있다면 그것은 일회성이 아닙니다.

## 여러 기간의 추세와 동종 기업 비교

**한 분기 숫자만으로는 판단할 수 없습니다.** 최소 3~5년을 나란히 놓고 봅니다.

```
         2022    2023    2024    2025
매출     1,000   1,200   1,500   1,600
영업이익   100     130     180     150
영업이익률 10%    10.8%   12%     9.4%
```

매출은 계속 늘었는데 2025년에 이익률이 떨어졌습니다. 왜 그런지가 다음 질문입니다. 원가가 올랐는지, 판촉비를 늘렸는지, 수익성 낮은 매출이 늘었는지.

계절성이 있는 업종은 **전년 동기와 비교**합니다. 4분기와 3분기를 비교하면 계절 효과를 실적 변화로 착각합니다.

동종 기업 비교는 **같은 기준**으로 해야 합니다. 회계 기준이 다르거나 사업 구성이 다르면 같은 지표도 의미가 다릅니다.

```
         이 회사   A사    B사
영업이익률   12%    8%     15%
부채비율     80%   150%    60%
ROE          15%   10%     18%
```

차이가 나는 항목에서 질문이 시작됩니다. **왜 이 회사가 더 높은가, 그것이 유지될 수 있는가.**

숫자를 읽을 수 있게 되었다면, 이제 그 숫자로 가격이 적절한지 판단하는 단계로 넘어갑니다.
