# JavaScript 학습 로드맵

브라우저와 서버에서 실행되는 JavaScript의 문법과 실행 원리를 익힙니다.

::: tip 학습 목표
**할 일 데이터를 다루는 작은 프로그램**를 완성합니다. 각 단계의 개념을 코드에 적용하고 완료 기준으로 이해도를 확인하세요.
:::

## 전체 학습 순서

| 단계 | 주제 |
| --- | --- |
| 01 | 실행 환경과 기본 문법 |
| 02 | 함수와 데이터 처리 |
| 03 | 스코프와 객체 모델 |
| 04 | 비동기 처리 |
| 05 | 모듈과 검증 |

## 01. 실행 환경과 기본 문법

- 브라우저 콘솔과 런타임
- 변수 선언
- 원시 타입
- 연산자
- 조건문과 반복문

**완료 기준:** 입력값을 검사하고 조건에 따라 결과를 출력할 수 있습니다.

## 02. 함수와 데이터 처리

- 함수 선언
- 매개변수와 반환값
- 배열과 객체
- 구조 분해
- 배열 메서드

**완료 기준:** 할 일의 추가·수정·삭제·필터링을 함수로 구현할 수 있습니다.

## 03. 스코프와 객체 모델

- 스코프
- 클로저
- this
- 프로토타입과 클래스
- 참조와 복사

**완료 기준:** 변수가 유지되는 범위와 객체 변경이 다른 참조에 미치는 영향을 설명할 수 있습니다.

## 04. 비동기 처리

- 호출 스택
- 이벤트 루프
- Promise
- async/await
- 예외 처리

**완료 기준:** 여러 비동기 작업의 순서를 제어하고 실패를 처리할 수 있습니다.

## 05. 모듈과 검증

- import와 export
- 모듈별 책임 분리
- 패키지 관리
- 단위 테스트

**완료 기준:** 데이터 처리 코드를 모듈로 분리하고 핵심 규칙을 테스트할 수 있습니다.

## 마무리 프로젝트

- 데이터를 추가·조회·수정·삭제하는 기능을 구현합니다.
- 잘못된 입력과 빈 데이터를 처리합니다.
- 핵심 로직의 성공·실패 사례를 테스트합니다.
- 실행 방법과 배운 내용을 README에 기록합니다.
