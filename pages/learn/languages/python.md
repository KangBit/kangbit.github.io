# Python 학습 로드맵

읽기 쉬운 문법으로 데이터를 처리하고 반복 작업을 자동화하는 기본기를 익힙니다.

::: tip 학습 목표
**파일에 저장하는 명령행 할 일 관리 프로그램**를 완성합니다. 각 단계의 개념을 코드에 적용하고 완료 기준으로 이해도를 확인하세요.
:::

## 전체 학습 순서

| 단계 | 주제 |
| --- | --- |
| 01 | 실행 환경과 기본 문법 |
| 02 | 컬렉션과 함수 |
| 03 | 파일과 예외 처리 |
| 04 | 모듈과 객체 |
| 05 | 타입 힌트와 테스트 |

## 01. 실행 환경과 기본 문법

- 인터프리터
- 가상 환경
- 변수와 기본 타입
- 들여쓰기
- 조건문과 반복문

**완료 기준:** 독립된 실행 환경에서 스크립트를 실행할 수 있습니다.

## 02. 컬렉션과 함수

- 리스트
- 튜플
- 딕셔너리
- 집합
- 슬라이싱
- 컴프리헨션
- 함수 인자와 반환값

**완료 기준:** 목록에서 필요한 데이터를 선택하고 변환할 수 있습니다.

## 03. 파일과 예외 처리

- 경로 처리
- with 문
- 텍스트와 JSON 읽기·쓰기
- 예외 처리

**완료 기준:** 파일이 없거나 데이터 형식이 잘못된 경우를 처리할 수 있습니다.

## 04. 모듈과 객체

- 모듈과 패키지
- 클래스
- 인스턴스
- 데이터 클래스
- 이터레이터와 제너레이터

**완료 기준:** 입출력과 핵심 로직을 나누고 필요한 데이터를 순차적으로 처리할 수 있습니다.

## 05. 타입 힌트와 테스트

- 함수 타입 힌트
- 의존성 기록
- 단위 테스트
- 명령행 인자

**완료 기준:** 재현 가능한 실행 방법을 정리하고 데이터 처리 규칙을 자동으로 검증할 수 있습니다.

## 마무리 프로젝트

- 데이터를 추가·조회·수정·삭제하는 기능을 구현합니다.
- 잘못된 입력과 빈 데이터를 처리합니다.
- 핵심 로직의 성공·실패 사례를 테스트합니다.
- 실행 방법과 배운 내용을 README에 기록합니다.
