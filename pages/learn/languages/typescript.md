# TypeScript 학습 로드맵

JavaScript 코드에 타입을 정의하고 안전하게 변경하는 방법을 익힙니다.

::: tip 학습 목표
**JavaScript로 만든 데이터 처리 모듈을 TypeScript로 옮기는 프로젝트**를 완성합니다. 각 단계의 개념을 코드에 적용하고 완료 기준으로 이해도를 확인하세요.
:::

## 전체 학습 순서

| 단계 | 주제 |
| --- | --- |
| 01 | 준비와 기본 타입 |
| 02 | 데이터 모델과 함수 |
| 03 | 유니온과 타입 좁히기 |
| 04 | 재사용 가능한 타입 |
| 05 | 프로젝트 적용과 경계 검증 |

## 01. 준비와 기본 타입

- JavaScript 기초 복습
- 컴파일과 실행의 차이
- 타입 추론
- 기본 타입과 배열

**완료 기준:** 타입 검사와 JavaScript 실행을 구분하고 오류를 수정할 수 있습니다.

## 02. 데이터 모델과 함수

- 객체 타입
- type과 interface
- 선택 속성
- 읽기 전용 속성
- 함수 입출력 타입

**완료 기준:** 할 일 데이터와 데이터 처리 함수의 계약을 타입으로 표현할 수 있습니다.

## 03. 유니온과 타입 좁히기

- 리터럴 타입
- 유니온
- 판별 유니온
- unknown
- 타입 가드
- null 처리

**완료 기준:** 로딩·성공·실패 상태를 구분하고 안전하게 속성에 접근할 수 있습니다.

## 04. 재사용 가능한 타입

- 제네릭
- 제약 조건
- keyof
- 인덱스 접근 타입
- 유틸리티 타입

**완료 기준:** 여러 데이터 모델에서 사용할 수 있는 함수를 타입 정보와 함께 작성할 수 있습니다.

## 05. 프로젝트 적용과 경계 검증

- 엄격한 타입 검사
- 모듈
- 타입 선언
- 외부 데이터의 런타임 검증

**완료 기준:** 타입 단언에 의존하지 않고 외부 입력을 검증해 내부 모델로 변환할 수 있습니다.

## 마무리 프로젝트

- 데이터를 추가·조회·수정·삭제하는 기능을 구현합니다.
- 잘못된 입력과 빈 데이터를 처리합니다.
- 핵심 로직의 성공·실패 사례를 테스트합니다.
- 실행 방법과 배운 내용을 README에 기록합니다.
