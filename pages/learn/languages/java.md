# Java 학습 로드맵

정적 타입과 객체 지향을 바탕으로 프로그램을 구조화하는 방법을 익힙니다.

::: tip 학습 목표
**파일에 저장하는 명령행 할 일 관리 프로그램**를 완성합니다. 각 단계의 개념을 코드에 적용하고 완료 기준으로 이해도를 확인하세요.
:::

## 전체 학습 순서

| 단계 | 주제 |
| --- | --- |
| 01 | 실행 환경과 기본 문법 |
| 02 | 클래스와 객체 |
| 03 | 컬렉션과 제네릭 |
| 04 | 예외와 데이터 처리 |
| 05 | 빌드와 테스트 |

## 01. 실행 환경과 기본 문법

- JDK와 JVM
- 컴파일과 실행
- 기본 타입과 참조 타입
- 조건문과 반복문

**완료 기준:** 소스 파일을 컴파일하고 실행하는 과정을 설명할 수 있습니다.

## 02. 클래스와 객체

- 필드와 메서드
- 생성자
- 접근 제어
- 캡슐화
- 인터페이스와 합성

**완료 기준:** 데이터와 동작의 책임을 나누어 클래스를 설계할 수 있습니다.

## 03. 컬렉션과 제네릭

- List
- Set
- Map
- 제네릭
- equals와 hashCode

**완료 기준:** 중복과 검색 요구에 맞는 컬렉션을 선택할 수 있습니다.

## 04. 예외와 데이터 처리

- 예외 처리
- 자원 관리
- 파일 입출력
- 람다
- Stream

**완료 기준:** 파일 자원을 정리하고 목록 데이터를 필터링·변환할 수 있습니다.

## 05. 빌드와 테스트

- 빌드 도구의 역할
- 의존성 관리
- 패키지 구성
- 단위 테스트

**완료 기준:** 프로젝트를 빌드하고 주요 기능의 성공·실패를 검증할 수 있습니다.

## 마무리 프로젝트

- 데이터를 추가·조회·수정·삭제하는 기능을 구현합니다.
- 잘못된 입력과 빈 데이터를 처리합니다.
- 핵심 로직의 성공·실패 사례를 테스트합니다.
- 실행 방법과 배운 내용을 README에 기록합니다.
