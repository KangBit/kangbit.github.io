# TypeScript 학습 로드맵

JavaScript 코드에 타입을 정의하고 안전하게 변경하는 방법을 익힙니다.

## 전체 학습 순서

| 단계 | 주제 |
| --- | --- |
| 01 | 준비와 기본 타입 |
| 02 | 데이터 모델과 함수 |
| 03 | 유니온과 타입 좁히기 |
| 04 | 재사용 가능한 타입 |
| 05 | 프로젝트 적용과 경계 검증 |

## 01. 준비와 기본 타입

- JavaScript 기초 복습
- 컴파일과 실행의 차이
- tsconfig의 주요 옵션
- 타입 추론
- 기본 타입과 배열

## 02. 데이터 모델과 함수

- 객체 타입
- type과 interface
- 선택 속성
- 읽기 전용 속성
- 함수 입출력 타입
- satisfies로 추론을 유지한 채 검사하기

## 03. 유니온과 타입 좁히기

- 리터럴 타입
- 유니온
- 판별 유니온
- unknown과 never
- 타입 가드
- null 처리
- 타입 단언에 기대면 생기는 문제

## 04. 재사용 가능한 타입

- 제네릭
- 제약 조건
- keyof
- 인덱스 접근 타입
- 매핑된 타입과 조건부 타입
- 유틸리티 타입

## 05. 프로젝트 적용과 경계 검증

- 엄격한 타입 검사
- 모듈과 모듈 해석 방식
- 타입 선언과 선언 병합
- 외부 데이터의 런타임 검증
