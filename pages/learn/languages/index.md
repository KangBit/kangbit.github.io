# 언어 학습 로드맵

언어마다 문법과 실행 방식, 자주 부딪히는 지점이 다릅니다. 언어별로 익힐 주제를 순서대로 정리합니다.

## 언어별 로드맵

| 언어 | 다루는 범위 | 단계 |
| --- | --- | --- |
| [JavaScript](/learn/languages/javascript) | 문법과 실행 원리, 비동기 처리 | 5 |
| [TypeScript](/learn/languages/typescript) | 타입 정의와 경계 검증 | 5 |
| [Python](/learn/languages/python) | 데이터 처리와 반복 작업 자동화 | 5 |
| [Java](/learn/languages/java) | 객체 지향 구조화와 동시성 | 6 |
| [Go](/learn/languages/go) | 명시적인 오류 처리와 동시성 | 5 |

## 어디부터 볼까

- 웹 화면을 다룬다면 JavaScript에서 시작해 TypeScript로 이어집니다.
- 서버를 다룬다면 한 언어를 정해 익힌 뒤 [백엔드 로드맵](/learn/backend/)의 02단계로 넘어갑니다.
- 반복 작업 자동화가 목적이면 Python, 동시성과 단일 실행 파일 배포가 목적이면 Go가 시작점이 됩니다.
