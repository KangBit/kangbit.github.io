:::details 상세 {open}

글로벌 팬덤을 위한 소셜 네트워킹 플랫폼입니다. <br>
웹뷰 프론트엔드, 백엔드 API, Android/iOS 네이티브 기능을 함께 담당했습니다.

React 기반 웹뷰 프로젝트의 초기 구조를 구성하고 회원가입, 로그인, 다국어 처리, 알림, WebView 연동 흐름을 구현했습니다.<br>
Sendbird를 활용한 실시간 채팅과 OpenTok(Vonage)을 활용한 라이브 방송 기능을 개발하며 외부 솔루션과 서비스 요구사항 사이의 연동 이슈를 대응했습니다.

네이티브 영역에서는 로그인, 푸시 알림, 웹뷰 브릿지 연동을 구현했고,<br>
백엔드에서는 화면과 앱 기능에 필요한 API를 직접 개발하며 프론트엔드와 서버 사이의 데이터 흐름을 맞췄습니다.
:::

레거시 ejs/jquery 화면과 Express 서버의 구조를 정리하며 가독성과 유지보수성을 개선했습니다.<br>
중복된 화면 로직과 서버 코드를 모듈화하고 함수화했으며,<br>
직렬로 처리되던 API 호출을 병렬 구조로 수정해 데이터 조회 성능을 개선했습니다.

Loranet과 ThingPlug에서 수집된 데이터를 API로 수신해 적재하는 로직을 구현하고,<br>
추가 센서 데이터는 GCP IoT Core와 Pub/Sub을 통해 수집할 수 있도록 연동했습니다.

:::
