서비스 전체를 이해하고 문제를 해결하는 프론트엔드 개발자 강빛찬입니다.

초기에는 React 기반 프론트엔드부터 Android/iOS 네이티브 앱, Node.js 백엔드까지 직접 개발하며

서비스가 사용자에게 전달되는 흐름 전반을 경험했습니다.

현재는 Vue 기반 웹/하이브리드 앱 프론트엔드 개발에 집중하고 있으며,

화면 구현에 그치지 않고 WebView, Native, Backend 사이에서 발생하는 문제를 함께 살펴보고 해결하는 데 강점이 있습니다.

요구사항 분석과 화면 설계, API 연동, 공통 모듈 개발, QA 및 운영 이슈 대응까지 프로젝트 전반에 참여하며

서비스와 개발 과정에서 더 나은 방향을 찾는 개발자가 되려고 합니다.

## 경력

초기에는 풀스택 개발자로서 프론트엔드, 네이티브 앱, 백엔드 개발을 함께 담당했습니다.

센서 데이터를 수집하고 시각화하는 모니터링 시스템과

전세계 팬덤 네트워크를 위한 소셜 네트워킹 플랫폼을 개발하며

웹뷰, 네이티브 기능, 백엔드 API가 함께 동작하는 구조를 직접 설계하고 구현했습니다.

이 과정에서 하이브리드 앱에서 발생하는 인증, 알림, 채팅, 라이브 방송, 데이터 연동 이슈를 경험했고,

문제를 특정 영역에 한정하지 않고 전체 흐름 안에서 원인을 찾는 방식을 익혔습니다.

<br>

프론트엔드 개발에 집중하게 된 후에도 개발 프로세스 전반에 대한 이해를 바탕으로

기획·디자인·백엔드·네이티브 개발자와 함께 요구사항과 구현 방식을 조율했습니다.

기획과 설계 단계부터 화면 구조, API 스펙, WebView 연동 방식에 의견을 제시했고,

반복되는 UI와 비즈니스 로직은 공통 컴포넌트와 모듈로 정리해 재사용 가능한 구조를 만들었습니다.

또한 차트 라이브러리와 Sendbird 같은 외부 솔루션 연동 경험을 바탕으로 실시간 기능과 데이터 시각화 이슈를 함께 해결했습니다.

이러한 경험을 바탕으로 프로젝트 간 우선순위와 구현 방향을 조율하며 팀 내 프론트엔드 업무를 리드하기도 했습니다.

## 사람에게서 배우는 것을 좋아합니다

공자는 세 사람 중에 한 명의 스승이 있다고 했지만, 나아가 세 사람 모두가 스승이라고 생각합니다.

좋은 모습에서만 보고 배울 수 있는 것이 아니라 나쁜 모습도 반면교사 삼아 배울 수 있기 때문입니다.

이렇게 '배울 점 없는 사람은 없다' 라는 마음으로 끊임없이 배우려고 노력했고,

사람을 통해 배우는 것을 좋아하게 되었습니다.
